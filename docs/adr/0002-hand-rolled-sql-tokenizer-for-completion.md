# Hand-rolled SQL tokenizer for completion

Existing completion relied on single-line, single-keyword regex to detect context (`FROM`/`JOIN`/`UPDATE`/`INTO`, or a bare qualifier before the cursor). Delivering clause-aware, alias-resolving completion (table aliases, comma-joins, columns valid anywhere a column is grammatically valid) is not reliably achievable with regex — it breaks down on string literals, comments, and multi-line statements. We chose to write a small dependency-free Lua tokenizer/lexer rather than extend the regex further or add a parsing library, keeping Orbit dependency-free while making completion correctness tractable. The regex-based context detection is removed entirely rather than kept as a fallback, to avoid two overlapping context-detection engines.
